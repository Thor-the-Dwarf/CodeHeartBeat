CSV-Daten für eine Bestenliste verarbeiten

Eine Berufsschule möchte die Ergebnisse eines Programmierwettbewerbs automatisiert aus einer CSV-Datei einlesen und für die Veröffentlichung aufbereiten.

Ausgangssituation

Die erste Zeile der Datei enthält die Spaltenüberschriften. Jede weitere Zeile enthält den Namen einer teilnehmenden Person und die erreichte Punktzahl. Beide Werte sind durch ein Semikolon getrennt.

NamePunkte Ada95 Linus88

Arbeitsauftrag

Übertragen Sie den beschriebenen Ablauf auf der rechten Seite in ein Aktivitätsdiagramm.

  1. Stellen Sie den Start und das Ende der Verarbeitung dar.
  2. Lesen Sie die CSV-Daten ein und überspringen Sie die Kopfzeile.
  3. Prüfen Sie wiederholt, ob eine weitere Datenzeile vorhanden ist.
  4. Zerlegen Sie jede Datenzeile in Name und Punktzahl.
  5. Geben Sie für jede Person eine formatierte Ergebniszeile aus.
  6. Beschriften Sie die ausgehenden Kontrollflüsse einer Entscheidung eindeutig.

Bedienung

  • Baustein oben halten und in das Raster ziehen.
  • Elemente durch Ziehen neu positionieren.
  • Beschriftungen durch Doppelklick bearbeiten.
  • Am Rand eines Elements einen Anschluss wählen und danach das Zielelement anklicken.
  • Pfeilbeschriftungen durch Doppelklick bearbeiten.
  • Mit Strg beziehungsweise Cmd und Mausrad zoomen.

Die Arbeitsfläche wird automatisch in diesem Browser gespeichert. Eine fachliche Auswertung ist in diesem Prototyp noch nicht enthalten.
